# Root Loose Notes

这里保存的是原先散落在根目录、但又不想丢掉的东西。

它们和 `collections/history/` 的区别在于：

- `history/` 更像一整段早期学习集中营
- `root_loose/` 更像后来陆续散落在工作台上的单文件实验

现在这里被拆成：

- `scripts/01_ui_and_layout/`：界面和布局小实验
- `scripts/02_topic_scripts/`：Minecraft、OSU 等主题脚本
- `scripts/03_color_and_image_tools/`：颜色选择、颜色提取、简易爬虫
- `scripts/04_scratch_pad/`：随手练习和命名随缘的草稿
- `assets/ui/`、`assets/images/`、`assets/data/`：对应素材
- `notes/`：零散便签
