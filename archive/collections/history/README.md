# History Notes

`history/` 是这次归档里最核心的一层，基本可以当成早期 Python 学习记录来看。

现在它被拆成七类：

- `01_basics_syntax/`：基础语法和控制流
- `02_flow_and_functions/`：函数、递归、数学和小算法
- `03_text_and_files/`：文件读写、文本材料、词频上下文
- `04_images_and_wordcloud/`：图片、词云、图像相关实验
- `05_network_and_tools/`：网络探测和小工具
- `06_packaging_and_apps/`：较完整的小应用与打包尝试
- `07_scratch_and_misc/`：跨语言、临时草稿和不易归类的文件

如果要从最“像学习过程”的地方开始回看，这个目录就是入口。
