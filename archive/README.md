# Archive

这是 `D:\py` 的归档区。

它不是“垃圾桶”，而更像一个学习陈列室：把过去几年写过的练手脚本、课堂作业、零散实验、打包产物和素材重新放好，让这段 Python 学习过程有一个能回看的位置。

## 归档后结构

- `collections/`：按原来的学习主题保留的目录集合。
- `generated/`：历史上生成出来的 `build/`、`dist/` 打包产物。
- `root_loose/`：原先散落在根目录的脚本、素材和便签。
- `environment/`：对当前环境和依赖快照的说明。
- `TIMELINE.md`：按时间整理的学习推进线。
- `HIGHLIGHTS.md`：像年终总结一样提炼出来的高光时刻。

## 快速印象

- `collections/history/` 是最像“手写学习日志”的部分，现在又细分成了基础语法、函数算法、文本文件、图片词云、网络工具、打包应用、杂项草稿七类。
- `collections/homewk/`、`collections/OOP/`、`collections/OSU!/`、`collections/CTF/` 也进一步拆成了脚本、数据、素材、运行记录等更具体的小区。
- `generated/` 的体积最大，主要是 PyInstaller 生成物，纪念意义大于实用意义。
- `root_loose/` 则保留了根目录原本那种“写到哪儿放到哪儿”的真实状态。

## 这次整理没有做的事

- 没有统一重命名旧文件。
- 没有删除看起来“没用”的历史内容。
- 没有尝试修复旧脚本能否在今天直接运行。
- 没有改动后期较完整、仍留在根目录的项目。

## 建议阅读顺序

1. 看 `CATALOG.md`，先知道各区都放了什么。
2. 看 `MEMOIR.md`，把这些目录当成一个学习时间轴来读。
3. 看 `TIMELINE.md` 和 `HIGHLIGHTS.md`，把散落文件重新串成成长过程。
4. 如果想恢复运行环境，再看 `environment/README.md`。
